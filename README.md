# 📚 Guia de Estudos de Idiomas

Este repositório foi estruturado para organizar anotações, vocabulário, exercícios e recursos de estudo de idiomas (como Inglês e Russo).

## 🗂️ Estrutura do Repositório

```text
estudo-de-idiomas/
├── english/
├── russian/
└── README.md
```
