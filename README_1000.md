# Versão 1000 frases

A página `index_1000.html` é autocontida: HTML, CSS, JavaScript e banco de dados estão no mesmo arquivo.

## Conteúdo
- 1–500: repertório-base fornecido.
- 501–1000: variações contextualizadas para reforço.
- 11 idiomas: PT, EN, ES, FR, DE, RU, HE, AR, HI, ZH, NO.

## Recursos
Busca instantânea, filtros, carregamento incremental, favoritos, progresso salvo em `localStorage`, TTS, flashcards, quiz, tema escuro/claro, frase aleatória e atalhos `/`, `R`, `F`, `Q`.
